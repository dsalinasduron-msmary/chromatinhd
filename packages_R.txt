NOTES
- scCustomize is NOT needed. step-0 originally loaded library(scCustomize), but
  no scCustomize release (1.1.0 - 3.3.0) exports WriteH5MU; it comes from
  MuDataSeurat. No other code in the repo uses scCustomize. Fixed in step-0.
- MuDataSeurat is GitHub-only and unmaintained (last commit 2023-11-14).
  Confirmed on our object: it fails on Seurat v5 Assay5 ("no slot of name
  meta.features") and on WNN graphs with no assay.used. Signac ChromatinAssay
  (ATAC) writes fine. step-0 works around both: rebuilds RNA as a v3 Assay
  and drops @graphs.
- WriteH5MU's choice of .X: if the assay has scale.data, .X = scale.data
  (often only variable genes); if counts + data, .X = data. Our SCT assay has
  scale.data for 3000 genes only, which writes an invalid modality, so step-0
  drops SCT and writes the chosen expression as mod/RNA:
    lognorm -> NormalizeData() of the joined raw RNA counts (40107 genes)
    sct     -> SCT `data` layer (39816 genes)
  Raw counts go to layers['counts'] in both cases.
- Signac ChromatinAssays store the fragment-file path(s) and cell barcodes;
  inspect them to settle potential_issues.txt item 5a.
- Ubuntu also ships binaries (r-cran-seurat, r-cran-dplyr, r-cran-hdf5r, ...),
  which would be faster to install, but we are building from CRAN source
  to get current versions and avoid mixing apt and CRAN copies.
